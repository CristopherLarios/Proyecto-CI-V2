Lo que aprendí en el curso

  1. Control de versiones: Aprendí que Git permite registrar los cambios de un proyecto y consultar su historial. Con git status puedo revisar qué archivos he modificado.
  2. Trabajo con ramas: Comprendí que las ramas permiten desarrollar funcionalidades sin modificar directamente la versión principal. Utilizo git switch -c para crear una rama nueva y trabajar en ella.
  3. Guardar cambios: Aprendí a utilizar git add para preparar los archivos y git commit para registrar mis avances con un mensaje descriptivo.
  4. GitHub y repositorios remotos: Comprendí cómo compartir proyectos y trabajar con otros desarrolladores. Utilizo git push para enviar mis commits al repositorio remoto.
  5. Recuperación de cambios: Practiqué comandos como git revert, git reflog y git stash para deshacer, localizar o guardar cambios temporalmente.
  6. Dificultad y solución: Durante una práctica, Git rechazó un push porque el repositorio remoto tenía cambios que aún no estaban integrados en mi computadora. Revisé el historial y utilicé git fetch y git pull --rebase para actualizar mi rama antes de volver a ejecutar git push. Así comprendí la importancia de sincronizar los repositorios.
