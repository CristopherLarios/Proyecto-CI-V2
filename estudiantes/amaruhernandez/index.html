Lo que aprendí en el curso

  1. El primer tema fue una Introduccion del curso hablando acerca de >programas de control de versiones
  2. Una vez aprendido que son los SCV el profesor nos presento Git y lo instalamos
  3. Empezando a ver comandos vimos el comando git init en nuestro directorio principal
  4. Luego de ver git init vimos comandos de iniciacion como:
    • git add
    • git status
    • git commit
  5. luego de los comandos esenciales vimos git stash
  6. Aprendimos a conectar nuestro directorio local con nuestro repositorio remoto en GitHub
  7. luego de git stash vimos los comandos
    • git revert
    • git merge
    • git rebase
    • git clone
    • git --no-ff
    • git fetch
    • git pull
    • git push
    • git switch
    • Entre otros

  8. Principalmente me confundio un poco el tema de git revert por que primero es algo muy delicado que si se hace mal puede llegar a costar todo el trabajo al igual que los conflictos
