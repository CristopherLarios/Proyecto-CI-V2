Lo que aprendí en el curso

  1. Aprendí a hacer un fork y copiar el proyecto a mi computadora con git clone.
  2. Aprendí a conectar el repositorio original con git remote add upstream y revisarlo con git remote -v.
  3. Aprendí a trabajar en mi propia rama con git switch -c y a guardar cambios con git add y git commit.
  4. Lo que más me costó fue entender la diferencia entre origin y upstream; lo resolví siguiendo la guía paso a paso y comprobando cada comando antes de continuar.
